# MacExpert 1.0.0

第一个正式版：把剪贴板敲入、鼠标按键映射、平滑滚动和热键翻译收进同一个菜单栏应用。

## 主要功能

- **剪贴板敲入**：复制文本后按 `⌃⌘V` 逐键敲入当前窗口，`⌃⌘↩` 在结尾补回车；再按一次可中断。适合远程桌面、堡垒机和虚拟机。
- **鼠标按键映射**：把鼠标侧键、中键映射成任意键盘组合键；支持单击触发，发送前会等鼠标松开，避免和原按键抢顺序。
- **平滑滚动**：滚轮平滑、垂直/水平反向、快速滚动加速，替代 iScroll / Mos 一类工具。触控板、Magic Mouse 和 `⌘`+滚轮不受影响。
- **热键翻译**：按 `⌥Space` 呼出面板。单词/短语走双语词典，长文本走译文；支持流式输出，也可以关闭流式等完整结果一次显示。
- **菜单栏常驻**：菜单栏只保留模块开关、打开主窗口、检查更新和退出。关闭主窗口后不占用 Dock。
- **检查更新**：查询 GitHub Releases 的最新正式版，发现新版本时打开对应发布页，不自动下载或安装。

## 安装

要求：macOS 15 或更高版本，Apple 芯片。

1. 下载 `MacExpert-1.0.0.dmg`，打开后把 `MacExpert.app` 拖进「应用程序」。
2. **首次打开请右键 →「打开」**。这个包用本机自签证书签名，没有经过 Apple 公证，直接双击会被 Gatekeeper 拦下；在「系统设置 → 隐私与安全性」里点「仍要打开」也可以。
3. 按提示到「系统设置 → 隐私与安全性 → 辅助功能」开启 MacExpert。敲入、鼠标映射和滚动接管都依赖这个权限。
4. 从菜单栏打开主窗口，按需开启各模块。

## 已知限制

- 发布包未公证、未做 DMG 签名；这是当前自用分发的预期状态。
- 翻译需要兼容 OpenAI Chat Completions 的服务地址、模型名和 API Key。Key 保存在 `~/Library/Application Support/MacExpert/translation.key`，目录权限 0700、文件 0600，是当前用户可读的明文文件。
- 鼠标映射到 `⌃←` / `⌃→` 这类系统保留快捷键时，macOS 的合成事件支持不稳定；如果经常失效，建议把系统「左/右切换桌面」改成 `⌃1` / `⌃2`，再映射到对应组合。
- 检查更新只查询 GitHub 正式 Release；不会自动下载或替换应用。

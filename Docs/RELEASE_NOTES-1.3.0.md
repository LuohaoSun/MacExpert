# MacExpert 1.3.0

这版没有新增模块，主要是一次界面与文案打磨，外加几处交互修正。

## 界面与交互

- **统一视觉**：主窗口、弹窗和面板统一使用主题蓝；卡片补上裁剪和一层轻投影；键帽、分段控件与开关尺寸重新对齐；权限提示条补了描边。
- **鼠标映射编辑器重做**：窗口改为 480pt 宽、高度自适应；鼠标按键用分段选择器，旁边保留「按键识别」按钮；识别中单独显示提示条；删除、取消、保存收进底部操作栏，支持 Esc 取消、Return 保存。
- **系统监控**：两个菜单栏项之间可以直接切换弹窗，不用先关再点；关闭再打开某个菜单栏项时，网络仍在左、CPU/GPU 仍在右；GPU 不可用时隐藏对应曲线和图例；历史标题补上覆盖时长；80% 警告色改为橙色，下载曲线统一成主题蓝。
- **翻译面板**：加载状态区分为查词典、连接服务、翻译中；复制后短暂显示「已复制」；失败态增加「打开设置」；底部快捷键提示改为符号；设置页新增「有未保存的更改」提示。
- **状态与文案**：各页统一为「需要辅助功能权限 / 已关闭 / 检测未运行」等更直接的说法；剪贴板状态色重新分配；平滑滚动在效果全关时明确提示；系统监控关闭总开关时，菜单栏与采样设置整体禁用。

## 安装

要求：macOS 15 或更高版本，Apple 芯片。

1. 下载 `MacExpert-1.3.0.dmg`，打开后把 `MacExpert.app` 拖进「应用程序」。
2. **首次打开请右键 →「打开」**。这个包用本机自签证书签名，没有经过 Apple 公证，直接双击会被 Gatekeeper 拦下；在「系统设置 → 隐私与安全性」里点「仍要打开」也可以。
3. 按提示到「系统设置 → 隐私与安全性 → 辅助功能」开启 MacExpert。敲入、鼠标映射和滚动接管都依赖这个权限；系统监控不需要。
4. 从菜单栏打开主窗口，按需开启各模块。

## 已知限制

- 发布包未公证、未做 DMG 签名；这是当前自用分发的预期状态。
- 安全输入状态下，macOS 仍可能丢弃合成按键；MacExpert 不提前拦截，也不会重试或提示。
- 翻译需要兼容 OpenAI Chat Completions 的服务地址、模型名和 API 密钥。密钥保存在 `~/Library/Application Support/MacExpert/translation.key`，目录权限 0700、文件 0600，是当前用户可读的明文文件。
- 鼠标映射到 `⌃←` / `⌃→` 时，需要系统里的「左/右切换桌面」快捷键保持开启；如果改过系统快捷键，映射也要改成相同组合。
- GPU 利用率依赖显卡驱动通过 IOAccelerator 暴露 `Device Utilization %` 或 `Renderer Utilization %`；驱动不提供时菜单栏显示 `--`。
- 网络 Top 进程统计所有本地连接，代理或回环流量可能在两端各计一次；菜单栏总速率按系统主接口统计，两者不保证完全相等。
- 菜单栏空间不足时，系统可能把新图标放进隐藏区；先退出不用的菜单栏工具或腾出位置。
- 检查更新只查询 GitHub 正式 Release；不会自动下载或替换应用。

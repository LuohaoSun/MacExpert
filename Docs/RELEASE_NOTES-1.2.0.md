# MacExpert 1.2.0

这次把菜单栏监控做成了可以点开的详情，并把主窗口的监控页收成纯设置。

## 主要功能

- **独立详情弹窗**：点击网络图标只看网络详情，点击 CPU / GPU 图标只看处理器详情，不再共用一个页面。
- **处理器详情**：CPU / GPU 利用率、每核占用、最近 60 次采样曲线，以及占用 CPU 最高的 5 个进程。
- **网络详情**：实时上传 / 下载、当前接口、最近 60 次曲线，以及占用网络最高的 5 个进程，分别显示下行和上行速率。
- **Top 进程只在详情打开时采样**：关闭弹窗后立即停止，不常驻后台。
- **主窗口监控页改为纯设置**：只保留总开关、菜单栏项目开关、刷新间隔和隐私说明；实时数据和 Top 进程统一在菜单栏弹窗里看。
- **菜单栏更稳、更省 CPU**：两个监控项改为直接绘制、固定宽度，数值变化不再推动左侧菜单栏图标；网络紧凑值最多 4 个字符，超长时降级为 `--`。空闲 CPU 从长期约 50% 降到 1% 左右。
- **网络速率更稳**：忽略小于 0.2 秒的采样间隔，打开页面或激活 App 时不会再出现异常尖峰。
- **CPU 进程占用更准**：按 mach absolute time 的 timebase 换算，跑满单核的进程会正确显示接近 100%。

## 安装

要求：macOS 15 或更高版本，Apple 芯片。

1. 下载 `MacExpert-1.2.0.dmg`，打开后把 `MacExpert.app` 拖进「应用程序」。
2. **首次打开请右键 →「打开」**。这个包用本机自签证书签名，没有经过 Apple 公证，直接双击会被 Gatekeeper 拦下；在「系统设置 → 隐私与安全性」里点「仍要打开」也可以。
3. 按提示到「系统设置 → 隐私与安全性 → 辅助功能」开启 MacExpert。敲入、鼠标映射和滚动接管都依赖这个权限；系统监控不需要。
4. 从菜单栏打开主窗口，按需开启各模块；点菜单栏里的网速或 CPU / GPU 图标查看详情。

## 已知限制

- 发布包未公证、未做 DMG 签名；这是当前自用分发的预期状态。
- 翻译需要兼容 OpenAI Chat Completions 的服务地址、模型名和 API Key。Key 保存在 `~/Library/Application Support/MacExpert/translation.key`，目录权限 0700、文件 0600，是当前用户可读的明文文件。
- 鼠标映射到 `⌃←` / `⌃→` 这类系统保留快捷键时，macOS 的合成事件支持不稳定；如果经常失效，建议把系统「左/右切换桌面」改成 `⌃1` / `⌃2`，再映射到对应组合。
- GPU 利用率依赖显卡驱动通过 IOAccelerator 暴露 `Device Utilization %` 或 `Renderer Utilization %`；驱动不提供时菜单栏显示 `--`。
- 网络 Top 进程统计所有本地连接，代理或回环流量可能在两端各计一次；菜单栏总速率按系统主接口统计，两者不保证完全相等。
- 菜单栏空间不足时，系统可能把新图标放进隐藏区；先退出不用的菜单栏工具或腾出位置。
- 检查更新只查询 GitHub 正式 Release；不会自动下载或替换应用。
